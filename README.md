Friends Face Recognition with CNN
 
 - Project Overview

This project applies Computer Vision and Deep Learning to perform face recognition of characters from the TV show Friends (Chandler, Joey, Monica, Phoebe, Rachel, and Ross).
A CNN model is trained using detected faces from images and evaluated with accuracy metrics and a confusion matrix.
